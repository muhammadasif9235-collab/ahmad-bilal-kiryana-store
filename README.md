# Privacy Policy — Ahmad Bilal Kiryana Store

Last updated: November 26, 2026

**Ahmad Bilal Kiryana Store** (`com.aistudio.kiryana.abksgp`) respects user privacy. This application is designed to assist with kiryana store billing, stock/inventory management, customer khata (ledger), daily cashbook (roznamcha), and market rate display.

## How Data Is Handled
- **Local & Cloud Storage:** Store bills, item records, stock entries, and khata records are stored on the user's device, with optional cloud backup or sign-in features when used by the user.
- **Location:** Used only when permitted to help identify local market rates or share delivery location when placing an order.
- **Camera / Scanner:** Used only when permitted to scan product barcodes, QR codes, or card/receipt details.
